## Crewly App 0.2.0

Start with a conversation: connect a model provider, choose an assistant for
everyday work, writing or learning, and open a private chat.

- **Proactive teamwork.** Opt-in follow-ups can consult up to two available,
  permitted teammates and return one combined result. Live chat shows who is
  consulting whom. Reviews observe daytime hours, inactivity limits and DND.
- **Work for later.** Create reminders and recurring assistant tasks directly
  from a conversation, inspect their history and pause or cancel them. Retrying
  a lost save does not create duplicate schedules.
- **A more resilient interface.** Failed settings and thread views recover
  locally. Late requests cannot overwrite the next conversation; failed sends
  preserve newer drafts. Missing agent profiles and malformed live updates no
  longer take down the workspace.
- **Clearer everyday controls.** Search settings, distinguish your own messages,
  use visible mobile message actions, and save schedules without losing the
  action buttons below the phone keyboard.

The release is checked against a real disposable server in Chromium, including
19 settings sections, light/dark themes, failure recovery and narrow screens.
Model fixtures verify the integration, not the quality of a commercial model.

This archive is the web app bundled by Crewly Server 0.2.0. For hosting and
installation, use the matching server release. Your configured model provider
supplies the models; reminders and background work require an online server.
